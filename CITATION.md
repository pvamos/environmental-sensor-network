# Citation

## Umbrella repository

`environmental-sensor-network` is currently the project-level architecture,
documentation and research-output index. It does **not** have a separate
Zenodo DOI and is not currently intended to be archived through Zenodo's
GitHub software-release workflow.

GitHub citation metadata is provided in [`CITATION.cff`](CITATION.cff).
Its `preferred-citation` points to the BSc thesis, which remains the canonical
scholarly citation for the original research.


## Thesis

The canonical scholarly citation for the original BSc research is the thesis:

**Vámos, Péter (2026).** *Környezeti paraméterek mérése a tudomány és technológia fejlődésének tükrében – Egy skálázható szenzorhálózat megvalósításának tanulságai*. DOI: **10.5281/zenodo.22843091**.
